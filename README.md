## 为什么 CN2 GIA 这么贵

简单说：线路成本摆在那里。中国电信出海线路大致分几层——最常见的 163 骨干网便宜但晚高峰拥堵严重；CN2 GT 便宜一档，但从 2019 年起也开始拥堵；CN2 GIA 是其中最贵也最稳的一层，丢包少、延迟低。搬瓦工在官方介绍里给过一个直观数字：CN2 GIA 的 IP 转发价格能到每 Mbps 120 美元，1Gbps 满带宽跑一个月的账单约 10 万美元。理解了这个成本结构，就明白香港 CN2 GIA 年付 899.99 美元和 KVM 年付 49.99 美元之间的差价花在了哪里——前者买的是晚高峰也不堵的直连线路，适合游戏联机、实时应用和对延迟敏感的场景；后者只是普通线路里的一台能用的 VPS。
